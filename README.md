# JARVIS1.0

This repository will host a lightweight, system-aware assistant named FRIDAY — a compact, optimized follow-up AI to J.A.R.V.I.S. The initial branch `feature/add-friday` will contain a scaffold that integrates with OpenRouter / Google Gemini (via OpenRouter) and supports low-spec and full modes, async streaming, small disk-backed memory, and optional TTS hooks.

This README was created to initialize the repository so feature branches can be created.
